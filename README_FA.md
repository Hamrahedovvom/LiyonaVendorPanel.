# پنل فروشندگان لیونا

نسخه مینیمال اندروید که فقط آدرس زیر را داخل WebView تمام‌صفحه باز می‌کند:

https://liyona.ir/vendor-dashboard/

## رفتار اپ
- هنگام شروع، لودر آبی با آیکن لیونا نمایش داده می‌شود.
- پس از بارگذاری صفحه، هیچ منو، هدر یا کنترل اضافه‌ای از طرف اپ وجود ندارد.
- لاگین و کوکی‌ها داخل WebView حفظ می‌شوند.
- انتخاب و آپلود فایل از فرم‌های سایت پشتیبانی می‌شود.
- دکمه Back اندروید ابتدا به صفحه قبلی WebView برمی‌گردد.

## ساخت APK
پروژه را با Android Studio باز کنید، Gradle Sync را انجام دهید و سپس از Build > Generate App Bundles or APKs خروجی بگیرید.

Application ID: ir.liyona.vendorpanel
